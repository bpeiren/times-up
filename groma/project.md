title: Time's up
groma:

description: A small always-on-top class-hour timer for Windows
---

A bar on screen that fills green, then orange, then red as a class hour runs out, so a teacher can keep track of time. Classes come from a per-weekday schedule in a settings file next to the exe, so the app is portable. Written in Rust against the Win32 API to stay tiny in size and memory.
